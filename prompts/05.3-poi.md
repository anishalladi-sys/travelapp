# Prompt 05.3 — POI Research (Data + UI)

## Goal
Add saved-places (points of interest) with data layer and UI in one segment.

## Prerequisite
Segment 05.2 marked ✅.

## Tasks
1. Zod schema `lib/validations/poi.ts`: name (1–150), category enum
   (sight/food/nature/shopping/nightlife/other), address optional, priority
   enum (must_do/nice_to_have/if_time), visited boolean default false,
   link optional URL, notes optional.
2. Migration `points_of_interest` table: id, trip_id fk cascade, user_id,
   name, category, address, priority, visited, link, notes, timestamps.
   RLS `auth.uid() = user_id`. BOTH copies + setup doc.
3. Data layer `lib/data/poi.ts`: CRUD + toggleVisited, ownership-scoped,
   grouped by category. In-memory equivalents.
4. Server actions `app/trips/[id]/poi/actions.ts`: CRUD + toggle +
   `convertToItineraryAction` (copies name/notes into a new itinerary item on
   a chosen day, marks POI visited-or-kept; keep both records).
5. UI: "Places" section — grouped cards by category with priority badges,
   map-link-out buttons (Google + Apple Maps URL patterns from name/address,
   `target=_blank rel="noopener"`), visited toggle, add/edit dialog, empty/
   loading/error states, Reveal stagger.
6. No map SDK this phase (links only). Leaflet stays unused.
7. Tests: validation, CRUD, toggle, convert action, ownership isolation.

## Acceptance criteria
- CRUD + visited + map links + convert-to-itinerary verified in browser both
  modes; ownership enforced; tests green.

## Verification
- `npm test`, `npm run typecheck`, `npm run build`
- Devtools: interaction pass, mobile viewport, console clean.

Update `tasks/README.md` segment 05.3 when done.
