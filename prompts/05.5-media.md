# Prompt 05.5 — Media Gallery

## Goal
Add per-trip photo gallery with uploads, lightbox, and horizontal scroll
storytelling.

## Prerequisite
Segment 05.4 marked ✅.

## Storage decision (important)
- **Production:** Cloudflare R2 per accepted ADR-0002 (S3-compatible, signed
  URLs, zero egress). Implement server-side signed-URL upload/download.
- **Dev/in-memory mode:** abstract storage behind `lib/data/media.ts` with an
  in-memory/local-disk adapter so the app works without R2 credentials.
- Do NOT silently switch to Supabase Storage. If R2 credentials are
  unavailable, implement behind the abstraction, verify the dev adapter, and
  mark the R2 live check DEFERRED with setup steps in `SUPABASE_SETUP.md`
  (or a new `docs/operations/media-setup.md`).

## Tasks
1. Zod schema `lib/validations/media.ts`: caption optional (≤300); upload
   constraints: images only (jpeg/png/webp), max 10 MB per file, max 50 files
   per trip (enforce server-side, not just client).
2. Migration `trip_media` table: id, trip_id fk cascade, user_id, storage_key,
   caption, width/height optional, timestamps. RLS `auth.uid() = user_id`.
   BOTH copies + setup doc.
3. Storage abstraction `lib/data/media.ts`: `createUploadUrl`, `confirmUpload`,
   `listMedia`, `deleteMedia` — R2 adapter + dev adapter.
4. Server actions `app/trips/[id]/media/actions.ts`: request upload (returns
   signed PUT), confirm, delete (removes object + row), ownership enforced.
5. UI: horizontal-scroll gallery strip on trip detail (scroll-snap), lightbox
   dialog with caption + prev/next keyboard navigation, upload flow with
   progress + error states, delete with confirm, lazy `next/image` rendering.
6. Tests: validation (type/size rejections), CRUD via dev adapter, ownership
   isolation.

## Acceptance criteria
- Upload → display → delete works in dev mode in browser; oversized/wrong-type
  uploads rejected server-side; R2 live check either verified or explicitly
  deferred with setup documentation.

## Verification
- `npm test`, `npm run typecheck`, `npm run build`
- Devtools: gallery scroll, lightbox keyboard nav, upload error paths,
  mobile viewport, console clean.

Update `tasks/README.md` segment 05.5 when done.
