# Prompt 01.2 — Core UI Primitives

## Goal
Build the styled primitive layer every later page/module uses: editorial-travel
variants of the core components with states built in.

## Prerequisite
Segment 01.1 marked ✅.

## Context
- shadcn/ui components exist under `components/ui/` (verify inventory first).
- Rule: style/extend existing shadcn+Radix primitives — do not replace them.
- Design tokens from 01.1. CLAUDE.md: minimum comfortable mobile touch targets.

## Tasks
Create (or restyle where they exist) under `components/ui/` or
`components/editorial/` if clearly additive:
1. **Button** — primary/secondary/ghost/destructive, loading state, icon
   support, ≥44px touch height.
2. **Card** — paper surface, soft shadow, hover lift, media slot variant.
3. **Input/Field** — label, help text, error state with accessible
   `aria-describedby`, required indicator.
4. **Badge** — category/status variants matching palette.
5. **Dialog/Sheet** — confirm patterns (esp. destructive), focus trap verified.
6. **EmptyState** — illustration/emoji-free, serif headline + action slot.
7. **SectionHeader** — eyebrow + serif title + lede, for scroll sections.
8. **Timeline** — vertical timeline primitive (marker, connector, content slot)
   — this becomes the itinerary backbone in Phase 02.

Every interactive primitive: visible focus ring, keyboard operable, reduced
-motion aware (hover lifts/transitions disable).

## Acceptance criteria
- All primitives render correctly; keyboard + focus behavior verified.
- States (hover, focus, active, disabled, loading, error, empty) all present.

## Verification
- `npm run typecheck`, `npm run build`, `npm test`
- Manual: exercise each primitive in the demo page from 01.4 later; for now,
  create a temporary uncommitted preview route OR a story file — do not commit
  throwaway routes.

Update `tasks/README.md` segment 01.2 when done.
