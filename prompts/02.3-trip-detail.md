# Prompt 02.3 — Trip Detail: Scroll-Storytelling Itinerary

## Goal
Rebuild the trip detail page as the flagship scroll-storytelling experience:
hero, sticky day navigation, animated itinerary timeline, scroll progress.

## Prerequisite
Segment 02.2 marked ✅.

## Context
- Existing page: `app/trips/[id]/page.tsx` with day-grouped itinerary items.
- Timeline primitive (01.2) + StickyHeader/ScrollProgress/Reveal (01.3).
- Intensity: pinned-feel day sections, progress indicator tracking scroll,
  smooth anchor scrolling — all reduced-motion aware, CLS-safe.

## Tasks
1. Hero: trip title serif display, date range, destination, day count; cover
   treatment (gradient/pattern acceptable); trip edit + delete entry points
   preserved (delete keeps confirmation dialog).
2. Sticky day-nav: horizontal chip nav ("Day 1…N") pinning under the app
   header; active day syncs with scroll position (IntersectionObserver);
   click → smooth anchor scroll.
3. Itinerary as animated timeline: each day = Timeline section with items
   (time, title, notes, location); day sections Reveal on entry; ScrollProgress
   bound to itinerary scroll range.
4. Horizontal-scroll photo strip placeholder section (real media comes in
   Phase 05) — render only if media module exists by then, else omit cleanly.
5. Keep every server action intact — this is a presentation-layer rebuild.
6. Empty state: trip with no items → inviting "plan your first day" CTA.

## Acceptance criteria
- Day nav highlights correctly while scrolling in both directions.
- All itinerary CRUD still works after rebuild (add/edit/remove/reorder via
  editor page).
- Smooth on mid-range mobile profile; zero CLS from animations; reduced-motion
  static fallback.

## Verification
- `npm test`, `npm run typecheck`, `npm run build`
- Devtools: scroll perf trace, active-state accuracy, both viewports,
  keyboard navigation of day chips, console clean.

Update `tasks/README.md` segment 02.3 when done.
