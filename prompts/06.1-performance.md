# Prompt 06.1 — Performance and Core Web Vitals

## Goal
Measure and improve the completed app without weakening functional or accessibility behavior.

## Prerequisite
05.6 verified. Read `prompts/_CONVENTIONS.md` and `tasks/06-production/README.md`.

## Context and files
Inspect `app/`, motion components/hooks, chart/gallery client bundles, font loading, and `next.config.ts`. Use the actual installed Next/Tailwind versions. Do not assume a Lighthouse script exists.

## Tasks
1. Load performance and browser-testing skills. Build and serve locally in production mode. Use fixed synthetic trips with 20 itinerary entries, module data, and bounded image fixtures.
2. Record three baseline runs for home, trips list, new/edit forms, trip detail, and budget/media-heavy views: viewport, throttling, browser/tool version, LCP, CLS, JS transfer size, and interaction/scroll traces.
3. Fix only measured bottlenecks: correctly sized images with reserved dimensions, early hero/font loading, below-fold chart/gallery imports, observer/listener cleanup, and unnecessary state updates. Keep Server Components where possible; content must remain usable when motion is disabled.
4. Add regression checks for any behavior changed. Re-measure with the identical fixture/configuration and compare medians in `docs/audits/periodic/`.
5. Inspect slow-network and reduced-motion cases. Do not claim field INP from Lighthouse or equate TBT to INP. Document field monitoring needed if traffic data is unavailable.

## Acceptance criteria
Under the recorded representative lab setup: LCP <= 2.5 seconds and CLS <= 0.1; no recurring animation-induced long tasks in scroll traces. Aim for interaction latency <= 200 ms in measured interactions; clearly label lab evidence versus field CWV. Investigate any regression rather than dropping thresholds.

## Verification
`npm test`, `npm run lint`, `npm run typecheck`, `npm run build`, relevant `npm run test:e2e` checks, before/after browser traces. Record unavailable measurements as blocked; apply shared completion procedure and stop.
