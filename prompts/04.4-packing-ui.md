# Prompt 04.4 — Packing UI

## Goal
Build the packing checklist UI: grouped checklist, satisfying packed
interaction, progress, template flow.

## Prerequisite
Segment 04.3 marked ✅.

## Tasks
1. "Packing" section on trip detail (consistent section pattern).
2. Checklist grouped by category; each row: checkbox/toggle (animated check,
   reduced-motion safe), name, quantity stepper, delete with confirm.
3. Progress: "x of y packed" progress bar (aria-valuenow, not color-only).
4. Quick-add row per category; full add form if extra fields needed.
5. Template flow: "Start from template" → choose beach/city/hiking → items
   added (confirm what will be added).
6. Optimistic toggle with rollback; pending states; empty/loading/error states.
7. Keyboard-complete; touch targets ≥ 44px; Reveal stagger on list load.

## Acceptance criteria
- Toggle persists after reload (both modes); template add verified; progress
  correct; full keyboard operation.

## Verification
- `npm test`, `npm run typecheck`, `npm run build`
- Devtools: interaction pass, mobile viewport, console clean.

Update `tasks/README.md` segment 04.4 when done.
