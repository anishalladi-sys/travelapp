# Prompt 03.4 — Transport UI

## Goal
Build the transport UI: departure-ordered timeline with mode icons, booking
refs, cost display.

## Prerequisite
Segment 03.3 marked ✅.

## Context
- Transport actions/data from 03.3. Design system primitives from Phase 01.
- Same section pattern on trip detail as accommodations (03.2).

## Tasks
1. "Transport" section on trip detail (same tab/anchor pattern as stays).
2. Transport cards/timeline: mode icon (lucide), provider, from → to, depart/
   arrive with local formatting (date-fns), duration when arrive_at present,
   cost, booking ref copy button, notes.
3. Sorted by depart_at; Reveal stagger; Timeline or Card layout consistent
   with stays section.
4. Add/edit form (Dialog/Sheet): Zod-backed inline errors, pending state.
5. Delete: confirm dialog, optimistic remove with rollback.
6. States: empty/loading/error as in 03.2.
7. Nice-to-have (only if trivial): show the stay for the arrival night next to
   each leg (join by date) — skip cleanly if it complicates the model.

## Acceptance criteria
- Full CRUD verified in browser, both data modes; keyboard-complete;
  mobile-friendly timeline rendering.

## Verification
- `npm test`, `npm run typecheck`, `npm run build`
- Devtools: CRUD pass, keyboard pass, mobile viewport, console clean.

Update `tasks/README.md` segment 03.4 when done.
