# Prompt 04.2 — Budget UI

## Goal
Build the budget dashboard: category breakdown chart, expense list with quick
add, animated totals, over-budget signal.

## Prerequisite
Segment 04.1 marked ✅.

## Context
- Recharts is installed (^2.10.4) — use it for the category breakdown (donut
  or bar), client component, lazy-loaded below the fold.
- Server actions + aggregates from 04.1. Design system primitives.

## Tasks
1. "Budget" section on trip detail (consistent pattern with stays/transport).
2. Header stats: total spent, trip budget cap (if set) with remaining +
   over-budget state (color-coded, accessible — not color-only).
3. Category breakdown chart (Recharts, `ResponsiveContainer`, legend, tabular
   values listed alongside the chart for a11y).
4. Expense list: grouped or sorted by date, category badge, edit/delete with
   confirm.
5. Quick-add form: description + amount + category inline; full form via
   dialog for the rest.
6. Per-day spend strip (small bar row across trip days) — Recharts or CSS bars.
7. Animated counters (respect reduced-motion), Reveal stagger, full state
   coverage (empty/loading/error).

## Acceptance criteria
- Add/edit/delete + correct totals verified in browser in both modes.
- Chart renders on mobile; screen-reader-accessible data table equivalent.

## Verification
- `npm test`, `npm run typecheck`, `npm run build`
- Devtools: CRUD pass, chart rendering at 375px, keyboard pass, console clean.

Update `tasks/README.md` segment 04.2 when done.
