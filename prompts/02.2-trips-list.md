# Prompt 02.2 — Trips List Page Redesign

## Goal
Rebuild `/trips` as an editorial card grid with staggered reveals and a strong
empty state, preserving all existing CRUD entry points.

## Prerequisite
Segment 02.1 marked ✅.

## Context
- Existing page: `app/trips/page.tsx` (verify current data flow first).
- Server Component data fetch + client islands for interactions only.
- Card primitives from 01.2; Reveal stagger from 01.3.

## Tasks
1. Preserve list behavior (fetch user's trips, ownership scoping).
2. Editorial card grid: trip title serif, date range, destination, day-count;
   responsive 1/2/3 columns; staggered Reveal on load.
3. Create-trip entry: prominent CTA; creation flow (page/dialog as currently
   implemented) styled to match; keep server action unchanged.
4. Empty state: EmptyState primitive with a compelling "start your first trip"
   action.
5. Loading state (Suspense skeleton matching card layout) + error state with
   retry.
6. Metadata + noindex as appropriate for a private app page.

## Acceptance criteria
- Grid renders all trips with correct data; create flow works end-to-end.
- Empty/loading/error states verified (empty: fresh user; error: simulate).
- Reduced-motion → cards render statically.

## Verification
- `npm test`, `npm run typecheck`, `npm run build`
- Devtools: both viewports, console clean, keyboard pass, CRUD functional pass.
