# Prompt 07.1 — Full Product Functional Audit

## Goal
Produce reproducible evidence and a complete defect list across the integrated product. This segment audits; 07.2 performs final repairs.

## Prerequisite
06.5 verified. Read `prompts/_CONVENTIONS.md` and `tasks/07-final-qa/README.md`.

## Tasks
1. Inventory acceptance criteria for auth, trips, itinerary, stays, transport, budget, packing, documents, places, emergency contacts, media, motion, accessibility, offline behavior, and operations.
2. Create a coverage matrix connecting each criterion to an actual test or manual check. Use two synthetic local/test accounts and separate owned trips; never use real passports or production records.
3. Exercise create/read/edit/delete/reload, cancellations, duplicate submissions, pending/error recovery, invalid input, date/timezone boundaries, currency totals, packing idempotency, document expiry, POI conversion, and media cleanup. Check unauthorized requests defensively against the local fixture only.
4. Run browser flows at narrow/mobile/desktop sizes with keyboard and reduced motion. Inspect focus, console/network, stale data, scroll progress, offline state, account switching, and delete cascades.
5. Record every finding with stable ID, severity, affected paths, preconditions, exact reproduction, expected/actual outcome, and regression test recommendation in a dated `docs/audits/periodic/` report. Include tested revision/worktree, commands, tools, and unavailable checks. Do not silently fix application code during this audit.
6. Point tracker Notes to the report and hand off identified defects to 07.2.

## Acceptance criteria
Every requirement has evidence or an explicit gap. The report is complete and reproducible; completion means audit finished, NOT application release approved. Missing audit access is blocked rather than called complete.

## Verification
Run `npm test`, `npm run lint`, `npm run typecheck`, `npm run build`, `npm run test:e2e`, plus the manual matrix. Failing product checks may be recorded as findings for 07.2: this is the sole audit-to-repair handoff exception in the shared rules. Stop after reporting.
