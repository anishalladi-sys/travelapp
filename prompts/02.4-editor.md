# Prompt 02.4 — Itinerary Editor UX

## Goal
Rebuild the itinerary editing experience (`app/trips/[id]/edit`) for speed and
delight while keeping server-action correctness and keyboard accessibility.

## Prerequisite
Segment 02.3 marked ✅.

## Context
- IMPORTANT (verified): `app/trips/[id]/edit/page.tsx` edits TRIP METADATA
  (title/destination/dates), not itinerary items. Itinerary add/edit/remove
  UI lives on `app/trips/[id]/page.tsx` and its row/form components, backed by
  actions in `app/trips/actions.ts`.
- There is currently NO reorder action and no `sort_order` column; the data
  layer sorts by date/time. `@dnd-kit` is installed but unused. Persisting
  manual order requires: add `sort_order` to the itinerary table in BOTH
  migration copies (`docs/migrations/` canonical + `supabase/migrations/`),
  a `reorderItineraryItemAction`, and data-layer ordering support.
- Optimistic UI allowed ONLY where the action is idempotent/reliable with
  rollback on error.

## Tasks
1. Audit current editor flow end-to-end (add item, edit inline, remove,
   reorder) — list current friction points first.
2. Inline add: quick-add row per day (title + time), expanding to full form
   (notes, location). Enter-key submits; focus returns to next add row.
3. Inline edit: click item → edit-in-place with save/cancel; Escape cancels.
4. Remove: destructive confirm via Dialog; Undo toast pattern if cheap, else
   confirm only.
5. Reorder: @dnd-kit drag with keyboard alternative (move up/down buttons —
   a11y requirement), optimistic reorder with rollback.
6. All states: submitting (pending indicators), error (inline, actionable),
   empty day ("nothing planned yet" + quick add).
7. Keyboard-complete: entire flow usable without mouse.

## Acceptance criteria
- Add/edit/remove/reorder all functional and verified.
- Optimistic mutations roll back correctly on simulated failure.
- Full keyboard operation; focus management correct after mutations.

## Verification
- `npm test` (add editor interaction tests if testable), `npm run typecheck`,
  `npm run build`
- Devtools: keyboard-only pass, console clean, mobile viewport pass.

Update `tasks/README.md` segment 02.4 when done.
