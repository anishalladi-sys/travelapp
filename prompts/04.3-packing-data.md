# Prompt 04.3 — Packing: Schema + Data + Actions

## Goal
Add the packing list module backend following the established module pattern.

## Prerequisite
Segment 04.1 marked ✅ (sequence per tracker; 04.2 must also be ✅ before this
starts).

## Tasks
1. Zod schema `lib/validations/packing.ts`: name (1–100), category enum
   (clothing/toiletries/tech/documents/medical/other), quantity int ≥ 1,
   packed boolean default false.
2. Migration `packing_items` table: id, trip_id fk cascade, user_id, name,
   category, quantity, packed, timestamps. RLS `auth.uid() = user_id`.
   BOTH copies + setup doc.
3. Data layer `lib/data/packing.ts`: CRUD + `togglePacked` + bulk
   "add from template". In-memory equivalents.
4. Template presets (beach/city/hiking) as static seed lists in
   `lib/data/packing-templates.ts` — user picks one, items copied into trip.
5. Server actions `app/trips/[id]/packing/actions.ts`: CRUD + toggle + add-
   from-template; Zod + requireUserId + ownership + revalidatePath.
6. Tests: validation, toggle, template expansion, ownership isolation.

## Acceptance criteria
- CRUD + toggle + template add work in both modes; ownership enforced; tests green.

## Verification
- `npm test`, `npm run typecheck`, `npm run build`
- `npm run db:push` if credentials available, else deferred note.

Update `tasks/README.md` segment 04.3 when done.
