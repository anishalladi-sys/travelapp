# Prompt 06.5 — QA: Production Gates

## Goal
Verify hardening as a whole and repair regressions before final product audit.

## Prerequisite
06.4 verified. Read `prompts/_CONVENTIONS.md`, `tasks/06-production/README.md`, and the production-readiness requirements in `CLAUDE.md`.

## Tasks
1. Build an evidence table covering auth/ownership, migrations, inputs, error states, performance, accessibility, mobile, offline privacy, telemetry, CI, deployment/rollback preparation, and docs accuracy.
2. Run the full suite in the configured isolated test environment. Check a fresh database migration and an upgrade containing existing synthetic records. Verify migration mirror consistency; do not mutate production.
3. Repeat the principal browser journey with all modules and a slow network, reduced motion, keyboard-only input, and an offline/online cycle. Confirm offline snapshots are cleared at logout/account switch.
4. Recheck measured performance and accessibility targets on production-mode output. Inspect console/network and sanitized failure telemetry; distinguish field metrics, lab results, and unperformed checks.
5. Reproduce each defect, add regression coverage, fix its responsible layer, and rerun the affected checks. Reassess after three failed fix attempts; do not lower thresholds or skip tests.
6. Write a dated gate report under `docs/audits/periodic/` with commands, fixture/environment identifiers, results, blockers, and rollback readiness. No deployment is authorized by this prompt.

## Acceptance criteria
All applicable hardening gates have evidence; no unresolved critical/major defects or missing mandatory integration checks. Minor issues may be carried only with explicit user approval and recorded ownership.

## Verification
`npm test`, `npm run lint`, `npm run typecheck`, `npm run build`, `npm run test:e2e`, and the browser/integration checks above. If blocked, do not enter Phase 07. Apply shared completion procedure and stop.
