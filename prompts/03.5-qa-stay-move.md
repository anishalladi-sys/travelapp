## QA procedure (do all)

   `npm run build`.
2. **CRUD (browser, both data modes):** add/edit/delete stays and transport
   legs; validation errors (checkout < checkin, arrive < depart) surface
   inline; delete confirmations work; rollback on simulated failure.
3. **Ownership isolation:** User B cannot read/mutate User A's stays or
   transport via UI and via direct action invocation with A's record ids.
4. **RLS (if dev Supabase available):** attempt cross-user read via
   authenticated client → denied. If no credentials, mark DEFERRED explicitly.
5. **UI quality:** empty/loading/error states; keyboard pass; mobile viewport;
   copy-ref buttons; console clean; reveal animations reduced-motion safe.
6. Record defects with severity; fix critical+major now; re-verify.

## Acceptance criteria

  explicitly listed.
