# Prompt 06.3 — PWA and Read-Only Offline Basics

## Goal
Provide installation, an offline shell, and explicitly opted-in last-viewed trip basics without caching private credentials or documents.

## Prerequisite
06.2 verified. Read `prompts/_CONVENTIONS.md` and `tasks/06-production/README.md`.

## Context and files
Inspect manifest/icons under `app/` and `public/`, `next.config.ts`, existing PWA dependencies, and auth logout/account-switch paths. Verify current App Router compatibility before selecting the smallest service-worker integration; dependency presence is not implementation evidence.

## Tasks
1. Define a cache allowlist: versioned public static assets and offline shell. Never cache auth endpoints, mutation requests, authenticated HTML/RSC/API responses, signed URLs, document numbers, contacts, or media objects by default.
2. Add manifest, correctly sized icons, install metadata and a useful offline route. Verify update/activation handling and old-cache cleanup without unexpectedly reloading unsaved forms.
3. Offer an explicit device-storage opt-in for a minimal read-only trip title/dates/itinerary snapshot; disclose shared-device exposure. Scope storage by user, show saved timestamp/staleness, and provide clear-offline-data action. No background write queue.
4. On logout/account change, remove private snapshots and stop showing previous-user data. On network failure show offline state, not fake successful mutations. Disable mutations with an actionable reconnect message.
5. Test install/relaunch, offline refresh, stale snapshot, quota/storage failure, logout while offline, account switch, and service-worker update. Ensure an unrecognized user cannot recover another user's snapshot via normal UI.
6. Document cache policy and rollback/unregistration instructions in `docs/features/` or existing PWA documentation.

## Acceptance criteria
Installable on supported tested browsers; offline shell works; opted-in read-only snapshot is clearly marked; auth/private response caching excluded; cleanup/account isolation tested. Stop for clarification before expanding cached data categories.

## Verification
`npm test`, `npm run lint`, `npm run typecheck`, `npm run build`, `npm run test:e2e`; production-mode browser install/offline/update checks. Apply shared completion procedure and stop.
