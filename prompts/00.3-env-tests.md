# Prompt 00.3 — Env Vars + Test Baseline

## Goal
Document all environment configuration and establish the green verification
baseline that every later prompt depends on:
`npm test`, `npm run lint`, `npm run typecheck`, `npm run build`.

## Prerequisite
Segment 00.2 marked ✅.

## Context
- App has dual data modes: Supabase (env vars set) and in-memory store
  (`globalThis.__travelStore` in `lib/data/store.ts`) when env vars are absent.
- Env vars involved: `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`,
  (plus any service-side vars used), and the new `NEXT_PUBLIC_AUTH_MODE=demo`
  flag from 00.1.
- `.env.example` may not exist. Never read or commit real `.env.local` values.

## Tasks
1. Create `.env.example` listing every required/optional var with placeholder
   values and comments explaining each.
2. Verify in-memory mode end-to-end: run dev server with `NEXT_PUBLIC_AUTH_MODE=demo` and no Supabase env, exercise trips + itinerary CRUD + demo auth. Confirm demo fallback is disabled when the flag is unset. Record any breakage and fix.
3. Verify Supabase mode locally if credentials are available; if not available,
   document exactly how to configure it in `SUPABASE_SETUP.md` and mark the
   live check as deferred (never fabricate success).
4. Strengthen tests cheaply: server-action validation tests (Zod rejections),
   itinerary cascade/delete behavior, and one test that the demo-mode fallback
   is disabled by default.
5. Make sure all four verification commands pass in in-memory mode.
6. Write the verification baseline (commands + expected results) at the top of
   `docs/testing/testing-notes.md`.

## Acceptance criteria
- `.env.example` complete; no real secrets anywhere in the repo.
- In-memory mode works only with explicit non-production demo opt-in. Unset flags, missing real configuration, and production with demo enabled fail closed; never fall back from a failed real session.
- All four commands green; test count increased vs 9 baseline.

## Verification
- `npm test`
- `npm run lint`
- `npm run typecheck`
- `npm run build`
- Manual dev-server CRUD pass in in-memory mode.

Update `tasks/README.md` segment 00.3 when done.
