# Prompt 05.6 — QA: Prepare Modules

## Goal
Verify documents, places, emergency contacts, and media together; repair defects before Phase 06.

## Prerequisite
05.5 verified; read `prompts/_CONVENTIONS.md` and `tasks/05-modules-prepare/README.md` before execution.

## Tasks
1. Inspect the implemented actions, validations, adapters, and browser routes for all four modules. Use synthetic records only.
2. Add regression tests against actual actions/data functions: document expiry boundaries and masking; places conversion into a selected itinerary day without marking unvisited places visited; emergency contact CRUD and unknown-country state.
3. Verify authenticated ownership and parent-trip ownership in a disposable local/test database. Test reassignment to another user's trip is rejected. Never test against production data.
4. Exercise media upload, confirmation, display, caption, and deletion. Reject unsupported content, oversized files, forged storage keys, cross-user references, and over-quota uploads through defensive tests in the local adapter. Ensure pending/failed objects cannot be displayed as confirmed media.
5. Browser-check all forms, error recovery, dialogs, gallery keyboard navigation, mobile scroll, reduced motion, and print preview. Emergency numbers must have verified country context; no guessed fallback number.
6. Record defects in a dated report under `docs/audits/periodic/`; fix in-scope defects with regression tests and rerun affected flows. Required external checks that cannot run remain blocked, not verified.

## Acceptance criteria
All module acceptance criteria pass; no unresolved functional/security defects; R2 and database test-environment integration verified; no sensitive document data appears in logs or reports.

## Verification
Run `npm test`, `npm run lint`, `npm run typecheck`, `npm run build`, and `npm run test:e2e` using the configured local/test environment. Record browser/device settings and actual results. Apply the shared completion procedure and stop.
