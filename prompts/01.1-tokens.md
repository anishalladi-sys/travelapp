# Prompt 01.1 — Design Tokens & Typography

## Goal
Create the editorial-travel design foundation: warm paper palette, serif
display + sans body typography, grain/texture utilities — all wired into
theme tokens compatible with the verified installed Tailwind version.

## Prerequisite
Phase 00 QA (00.4) marked ✅.

## Context
- VERIFY FIRST: `package.json` shows `tailwindcss` ^3.4.0 but
  `@tailwindcss/postcss` ^4 is also installed — inspect `postcss.config.mjs`
  and `tailwind.config.*` to determine the effective major version before
  choosing CSS-first `@theme` (v4) vs JS config (v3) token wiring.
- Existing shadcn/ui setup with CSS variables (verify actual variable names).
- Direction (user-approved): warm paper tones (#faf6f0-ish range), deep ink
  text, one warm accent (terracotta/ochre family), soft shadows, generous
  spacing, subtle grain. Serif display headlines (e.g. Fraunces/Playfair class)
  + readable sans body (e.g. Inter). Use `next/font` for font loading.
- Accessibility: text contrast ≥ WCAG AA against paper backgrounds.

## Tasks
1. Inspect current `globals.css` / tailwind config / shadcn variable names.
2. Define palette tokens (background, surface, ink, muted, accent, accent-soft,
   border, ring), radii, shadow scale, spacing rhythm as CSS variables.
3. Add `next/font` serif display + sans body; set type scale (display, h1–h3,
   body, caption) with fluid `clamp()` sizing.
4. Grain/texture as a performant utility class (CSS-only, no layout cost,
   `pointer-events: none`, compositing-safe).
5. Keep dark-mode variables possible (structure tokens so `[data-theme=dark]`
  can override later — do not build dark mode now).
6. Apply tokens without changing page behavior — pages may look slightly
   different but must not break.

## Acceptance criteria
- New tokens live in CSS/Tailwind theme; typography renders serif/sans
  correctly; contrast checks pass for ink-on-paper and accent-on-paper.
- Existing pages still render without errors.

## Verification
- `npm run typecheck`, `npm run build`
- Manual: view each page in dev server; check font/spacing/colors applied;
  devtools contrast checker on key text.
- `npm test` still green.

Update `tasks/README.md` segment 01.1 when done.
