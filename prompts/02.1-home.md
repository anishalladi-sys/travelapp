# Prompt 02.1 — Landing / Home Page Redesign

## Goal
Rebuild the home page with the design system + scroll storytelling: parallax
hero, reveal sections, clear CTA into the app.

## Prerequisite
Phase 01 QA (01.4) marked ✅.

## Context
- Current home page exists (verify current content in `app/page.tsx` before
  replacing anything — Chesterton's Fence).
- Design system: `components/editorial/`, `components/motion/`, tokens in
  globals. Stack: Next.js App Router, Server Components by default;
  `"use client"` only where interactivity requires.
- Target intensity: parallax hero imagery (CSS gradients/illustration is fine —
  no heavy stock photos required), serif display headline, reveal-on-scroll
  feature sections, sticky CTA bar on mobile allowed.

## Tasks
1. Audit current home page content/behavior; preserve any working entry points
   (trips CTA, demo auth entry).
2. Build: parallax hero with headline + primary CTA; "how it works" section
   with Reveal staggering; feature trio (plan days, track stays, pack smart);
   footer.
3. Use `<Parallax>`, `<Reveal>`, SectionHeader primitives; CLS-safe.
4. SEO: proper metadata (title/description/OG) — this may be the indexable page.
5. Mobile-first responsive; reduced-motion degrades to static layout.

## Acceptance criteria
- Home page redesigned and functional on mobile + desktop.
- CTA routes correctly (to trips list or auth per current auth state).
- No console errors; Lighthouse quick-check shows no obvious perf regressions.

## Verification
- `npm test`, `npm run lint`, `npm run typecheck`, `npm run build`
- Devtools pass: console, network, scroll perf, both viewports, keyboard tab pass.

Update `tasks/README.md` segment 02.1 when done.
