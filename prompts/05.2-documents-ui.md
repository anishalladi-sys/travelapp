# Prompt 05.2 — Documents UI

## Goal
Build the documents UI: document cards with expiry warnings and a completeness
checklist view.

## Prerequisite
Segment 05.1 marked ✅.

## Tasks
1. "Documents" section on trip detail (consistent section pattern).
2. Document cards: type badge, title, masked number (reveal-on-demand client
   toggle), expiry date with countdown badge: expired (destructive), < 90 days
   (warning), else neutral. Badge state must not be color-only (icon/text).
3. Completeness strip: which essential types are missing for this trip
   (passport/insurance as defaults) with quick-add for missing ones.
4. Add/edit form (Dialog/Sheet), delete with confirm; pending/error/empty
   states.
5. Reveal stagger; keyboard-complete; touch targets ≥ 44px.

## Acceptance criteria
- CRUD verified in browser both modes; expiry logic correct (test boundary
  dates); no full number shown by default.

## Verification
- `npm test`, `npm run typecheck`, `npm run build`
- Devtools: interaction pass, mobile viewport, console clean.

Update `tasks/README.md` segment 05.2 when done.
