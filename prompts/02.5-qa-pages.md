# Prompt 02.5 — QA: Page Overhaul Phase

## Goal
Verify all four redesigned pages end-to-end in a real browser, fix every
defect, and close Phase 02.

## Prerequisite
Segments 02.1–02.4 marked ✅ in `tasks/README.md`.

## QA procedure (do all)
1. **Functional regression (browser):** home CTA → auth → trips list → create
   trip → detail → add/edit/remove/reorder itinerary → delete trip. All flows
   must work post-redesign.
2. **Scroll behavior:** day-nav active state tracks scroll both directions;
   anchor click scrolls smoothly; ScrollProgress accurate; no jank with 20+
   reveals (Performance panel trace).
3. **CLS/LCP:** zero layout shift from reveals/parallax; hero LCP element
   renders early (devtools Performance + Lighthouse quick run).
4. **Reduced motion:** Rendering panel emulation → all effects static, pages
   fully usable.
5. **Keyboard:** complete tab pass on every page; day chips operable; editor
   keyboard reorder works.
6. **Viewports:** 375px, 768px, 1440px — layout, touch targets, horizontal
   scroll affordances.
7. **Console/network:** zero errors; no 404 assets; no oversized bundles
   introduced.
8. Record defects with severity; fix critical+major now; re-verify.

## Acceptance criteria
- Zero open critical/major defects; all four commands green; QA results
  summarized in the segment report.

## Verification
- `npm test`, `npm run lint`, `npm run typecheck`, `npm run build`
- Full devtools pass as described.

Update `tasks/README.md` segment 02.5 (mark Phase 02 complete) when done.
